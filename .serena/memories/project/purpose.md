# Project purpose

This repo (`giannisCKS.github.io`) is a personal portfolio website for Giannis Papakostas, deployed to GitHub Pages.

## Tech stack
- Next.js (static export via `output: 'export'`)
- React + TypeScript
- Tailwind CSS
- ESLint (flat config via `eslint.config.mjs`)
- Unit tests: Vitest + jsdom + React Testing Library
